# Family Guardian Network

The Family Guardian Network is the agent layer for family life: protection, documentation, research, household coordination, extended-family gatherings, elder support, contact stewardship, and personal family hubs.

It is not a single all-knowing family bot. It is a permissioned set of agents with narrow responsibilities, explicit memory boundaries, and audit trails.

## Core Thesis

Families need more than planning. They need a trusted operating memory that helps them:

- keep contact data current without exposing everyone to everyone
- plan food, chores, travel, visits, and gatherings
- coordinate elder support without infantilizing older members
- document family stories and useful knowledge
- reduce misinformation by separating verified facts from guesses
- let each person build a private hub and optionally contribute approved material to the shared family hub
- preserve public-facing family libraries only when the family explicitly chooses to publish

## Agent Families

- Guardian Agent: safety, policy, consent, injection defense, and misinformation checks.
- Documentation Agent: family manuals, playbooks, event notes, decisions, and knowledgebase updates.
- Research Agent: source-grounded research for family decisions, vendors, health-adjacent logistics, travel, schools, and local services without making professional claims.
- Household Life Agent: food, groceries, chores, routines, maintenance, and weekly family operations.
- Gathering Organizer Agent: parties, holidays, reunions, invitations, food plans, accessibility needs, and after-action notes.
- Elder Support Agent: visits, care logistics, appointments, preferences, accessibility, trusted contacts, and emergency readiness.
- Contact Steward Agent: consented contact collection, verification, deduplication, provenance, and refresh reminders.
- Personal Hub Agent: helps each family member build a private library/site and submit approved artifacts to shared or public hubs.

## Memory Boundaries

Each agent works with scoped memory:

- Personal memory: private to the individual unless shared.
- Household memory: shared by members of a household.
- Extended-family memory: shared with invited relatives under explicit rules.
- Advisor memory: visible only to trusted advisors and owners.
- Public library memory: deliberately published, redacted, and attribution-reviewed.

No agent may move memory from a narrower scope to a broader scope without approval, provenance, and audit.
