# Family Memory Model

Family memory is the operational record of people, places, documents, events, rituals, assets, decisions, stories, and responsibilities.

MVP memory objects:

- family member
- relationship
- document
- photo/video memory
- household task
- calendar event
- finance summary
- emergency record
- decision log
- weekly review

Memory entries must carry family scope, sensitivity, source connector, provenance, timestamp, and audit context.
