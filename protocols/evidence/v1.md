# Evidence Protocol v1

## Evidence object

An evidence object describes a source artifact without assuming that the source proves a claim.

Required properties:

- evidence ID and family ID
- artifact kind and original-language title
- source URI or family-owned storage reference
- source grade and provenance chain
- rights status and allowed uses
- cryptographic digest when bytes are retained
- extraction actor, method, and timestamp
- sensitivity and living-person impact
- linked claim IDs

## Source grades

| Grade | Meaning |
|---|---|
| `A` | Contemporaneous official or original record with traceable custody |
| `B` | Reliable secondary record or independently corroborated source |
| `C` | Family document, oral history, or derivative source with useful context |
| `D` | Uncorroborated recollection, index hint, tree copy, or low-context source |
| `unknown` | Not yet assessed |

Grade is not the same as relevance. An official record can refer to the wrong person; an oral history can be the best available account when clearly labeled.

## Grading checklist

A source grade records the current support quality, not a permanent truth score.

| Check | Required handling |
| --- | --- |
| Custody | Record how the artifact reached the family or archive and whether the original is available. |
| Identity | Test whether the referenced person, place, date, or household could belong to a different person with the same or similar name. |
| Time | Record whether the artifact was contemporaneous, retrospective, copied, translated, or indexed later. |
| Completeness | Preserve visible omissions, illegible sections, alterations, and partial pages. |
| Independence | Do not count repeated copies of the same assertion as independent corroboration. |
| Rights | Separate evidentiary value from permission to share, publish, derive, or send to an AI service. |

Use grade `A` only when traceable custody and a contemporaneous/original record support the interpretation. Use `B` for reliable secondary or independently corroborated material. Use `C` for context-rich family material whose interpretation remains uncertain. Use `D` for a lead that needs research. Any unresolved identity collision, altered source, missing page, or unknown custody should prevent an automatic upgrade.

## Extraction boundaries

OCR, transcription, translation, entity extraction, and AI summaries are derived artifacts. They inherit the source's sensitivity, rights limits, consent requirements, and provenance reference. They never replace the original source and must retain uncertainty markers where the original is unclear.

## Attachments

Inbound attachments remain quarantined until malware/content checks and steward review complete. Public repositories and logs receive metadata only. Originals stay in family-owned encrypted storage where possible.
