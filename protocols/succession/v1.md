# Succession Protocol v1

Emergency, incapacity, and death are separate protocols.

| Protocol | Trigger | Default release |
|---|---|---|
| Emergency | Verified immediate need | Minimal read-only emergency packet |
| Incapacity | Authorized legal/guardian process | Delegated operational access, purpose-limited |
| Death | Verified death, cooling period, guardian quorum | Designated archive/assets only |

## Required policy controls

- designated continuity guardians
- minimum two-of-three quorum for death release by default
- verified trigger evidence and independent confirmation
- cooling and revocation windows
- staged release scopes
- no password/secret export by default
- immutable decision metadata with cryptographically deletable payloads
- restoration drill and last-tested timestamp

An inactivity timer alone never triggers release. Agents may prepare checklists and evidence packets but cannot determine death, incapacity, legal authority, or final release.
