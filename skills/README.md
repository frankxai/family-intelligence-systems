# Family Intelligence skills

These skills are reviewable workflow bundles. They do not grant authority by themselves. Runtime installation must enforce declared data scopes, tools, network domains, human approvals, retention, audit, and rollback.

Initial set:

- `ingest-lineage-claim`
- `capture-elder-story`
- `compare-conflicting-claims`
- `publish-family-biography`
- `prepare-emergency-packet`
- `request-family-consent`
- `extract-record-evidence`
- `export-gedcom-7`
- `run-succession-drill`

Public contributors submit changes through review. No customer or family data belongs in a skill fixture.
