# Run succession drill

## Rules

1. Select exactly one protocol: emergency, incapacity, or death.
2. Use synthetic trigger evidence and mark every artifact as a drill.
3. Verify designated guardians, quorum, cooling period, minimum release scope, expiry, revocation, and audit.
4. Never reveal real secrets, recovery codes, or unrestricted archives.
5. Require a human steward to start and close the drill.
6. Record gaps, owners, deadlines, and the next test date.

An agent coordinates checklists and evidence; it cannot verify a real trigger or perform a release.
