# Extract record evidence

## Rules

1. Operate only on a scanned artifact a human or security service has released from quarantine.
2. Keep original language, spelling, layout notes, and the immutable source reference.
3. Mark illegible or inferred text; never silently complete names or dates.
4. Extract candidate entities and claim links without accepting them.
5. Record source grade, rights status, permitted uses, affected living people, and checksum.
6. Never expose the artifact to an unapproved remote model or tool.

Output is evidence metadata and transcription for human review, not a lineage decision.
