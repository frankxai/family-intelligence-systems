# Einwilligung widerrufen oder Nutzung einschränken

Dies ist eine Arbeitsvorlage für das Familienarchiv, keine individuelle Rechtsberatung. Ein Widerruf betrifft die zukünftige Nutzung für den genannten Zweck; er macht eine Familienaussage nicht automatisch wahr oder unwahr.

## Antrag

- Name oder sicheres Pseudonym:
- Sichere Rückkontaktmöglichkeit:
- Betroffene Einwilligungs-ID, Aussage, Quelle oder Seite (falls bekannt):
- Ich handle für: `<mich selbst / Kind oder betreute Person / bevollmächtigte Person>`
- Grundlage meiner Vertretung (nur falls erforderlich):
- Gewünschte Einschränkung:
  - [ ] keine weitere Sammlung
  - [ ] keine weitere Speicherung oder Verarbeitung
  - [ ] keine Transkription, Zusammenfassung oder KI-Verarbeitung
  - [ ] keine Weitergabe im Familienkreis
  - [ ] Rücknahme oder Sperrung einer Veröffentlichung
  - [ ] keine künftigen Exporte
  - [ ] anderes: `<Beschreibung>`
- Ab wann soll die Einschränkung gelten?
- Möchtest du eine Bestätigung des Ergebnisses erhalten? `<ja/nein>`

## Was danach geschieht

1. Das Archiv bestätigt den Eingang, ohne zusätzliche private Details per E-Mail anzufordern.
2. Die Berechtigung wird sicher geprüft. Bei Unklarheit entscheidet kein Agent allein.
3. Nach erfolgreicher Prüfung werden künftige betroffene Vorgänge gestoppt.
4. Das Steward-Team prüft Quellen, Transkripte, Zusammenfassungen, Suchindizes, Exporte und öffentliche Seiten auf betroffene Ableitungen.
5. Öffentliche Materialien werden zuerst gesperrt oder zurückgenommen, soweit das Archiv sie kontrolliert.
6. Du erhältst eine knappe Bestätigung: gestoppt, entfernt, zur Prüfung vorgemerkt oder außerhalb unserer Kontrolle.

Bereits heruntergeladene Exporte, fremde Archive oder Nachrichten außerhalb des Systems können nicht technisch zurückgerufen werden. Das Archiv stoppt jedoch weitere Weitergabe und dokumentiert die verbleibende Einschränkung transparent.
