# Open-Source Readiness Gate

These repositories are public but are not yet permitted to claim open-source status because no human-approved OSI license and contributor-origin policy is in force.

## Human-gated decision

The founding steward must approve, with license review:

- software license for the runtime;
- doctrine/schema/documentation license;
- data/source-catalogue license;
- trademark and naming policy;
- DCO versus CLA contributor-origin model;
- compatibility with GPL projects such as Gramps and webtrees and with intended hosted/commercial use.

Candidate directions for review are Apache-2.0 for broad interoperability or AGPL-3.0 for network-copyleft. This document does not select either.

## Readiness checklist

- [x] Private family data excluded from public repositories.
- [x] Contribution and governance contracts exist.
- [x] Private security reporting path documented.
- [x] Synthetic-only public artifact rule exists.
- [x] Independent sensitive-change review required.
- [ ] Human-approved OSI license committed.
- [ ] Documentation/data licenses committed.
- [ ] DCO or CLA policy activated.
- [ ] Trademark/naming policy approved.
- [ ] Release provenance and public sanitization automated.

Until the unchecked gates are closed, accept only explicitly reviewed project-owned work; do not invite general public contributions or label a release open source.
