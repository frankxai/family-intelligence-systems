# Setup Contact Data Stewardship

1. Start with each member's own contact card.
2. Ask explicit consent for sharing phone, email, mailing address, birthday, and emergency contact data.
3. Store provenance for every field.
4. Mark stale or conflicting fields instead of overwriting.
5. Schedule lightweight verification prompts every 6 to 12 months.
6. Audit any export, bulk invite list, or external sharing.
