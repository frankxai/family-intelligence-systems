# Setup Family Guardian Network

1. Create the family owner and initial admin.
2. Define household, extended-family, advisor, and guest boundaries.
3. Enable Guardian Agent before enabling any other family-facing agent.
4. Configure audit writer and policy defaults.
5. Add Documentation, Research, Household Life, Contact Steward, Gathering Organizer, Elder Support, and Personal Hub agents as read-only assistants first.
6. Run a consent review before importing contacts, photos, or documents.
