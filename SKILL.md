# Family Intelligence Systems Skill

Use this repo when planning, documenting, or implementing Family Intelligence System architecture.

## Required Stance

1. Preserve adapter-first sovereignty.
2. Do not vendor upstream applications without license and security review.
3. Treat MCP as a controlled gateway.
4. Default all sensitive operations to read-only or blocked.
5. Keep `registry/*.yaml` and `LICENSE-AUDIT.md` synchronized when adding upstreams.
